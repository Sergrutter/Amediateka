Amediateka
Проект на Python, связанный с сервисом Amediateka (онлайн-кинотеатр).

🎯 Цель проекта
Проект создан для взаимодействия с сервисом Amediateka — онлайн-кинотеатром, предоставляющим доступ к фильмам, сериалам и другому видеоконтенту.

Основные задачи проекта:

Автоматизация работы с контентом/данными сервиса Amediateka

Демонстрация практических навыков разработки на Python

Учебный/пет-проект по разработке прикладного ПО

🛠️ Используемые технологии
Технология	Назначение
Python 3.x	Основной язык разработки
pip	Менеджер пакетов для установки зависимостей
requirements.txt	Управление зависимостями проекта
Git / GitHub	Система контроля версий и хостинг репозитория
Pillow (возможно)	Работа с изображениями (наличие Amediateka.jpg)
Полный список библиотек — в файле requirements.txt.

📁 Содержимое репозитория
Файл	Описание
Proekt_Amediateka.py	Основной скрипт проекта
Amediateka.jpg	Изображение (логотип/скриншот)
requirements.txt	Список зависимостей Python
README.md	Документация проекта
🚀 Установка
Клонируйте репозиторий:

bash
git clone https://github.com/Sergrutter/Amediateka.git
cd Amediateka
(Опционально) Создайте и активируйте виртуальное окружение:

bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate
Установите зависимости:

bash
pip install -r requirements.txt
▶️ Запуск
bash
python Proekt_Amediateka.py
